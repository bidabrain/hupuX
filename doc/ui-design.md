# hupuX 界面设计规范（Android）

> 一句话：**白底承载内容，虎扑红负责强调，中文标题负责信息，间距负责层级。**
>
> 改版目标是「看起来仍然是虎扑，但像一款重新设计过的现代体育社区 App」——
> 保留论坛的信息密度，去掉大面积色块。

---

## 一、颜色：只通过语义 Token 取色

**所有页面禁止写死颜色值**，一律用 `ui/theme/Theme.kt` 暴露的语义属性。
这样浅色、深色、AMOLED 三套配色能一次性覆盖全部页面——这也是为什么改版没有
新建一组扁平常量，而是改 `MaterialTheme.colorScheme` 的槽位。

| 语义属性 | 用途 | 浅色 | 深色 | AMOLED |
|---|---|---|---|---|
| `AppBg` | 页面背景 | `#F6F7F8` | `#0F1118` | `#000000` |
| `CardBg` | 卡片 / 顶栏 / 底栏 | `#FFFFFF` | `#1A1E28` | `#000000` |
| `TextPrimary` | 主标题 | `#18181B` | `#E4E8F2` | `#E4E8F2` |
| `TextSecondary` | 摘要、次要文字 | `#71717A` | `#8A90A0` | `#8A90A0` |
| `TextTertiary` | 时间、互动数 | `#A1A1AA` | `#5A6070` | `#5A6070` |
| `DividerColor` | 分割线 | `#E5E7EB` | `#252A38` | `#1A1A1A` |
| `BgGray` | 中性 chip 底 | `#F1F2F4` | `#1E2330` | `#121212` |
| `HotColor` | 热度数字 | `#F04438` | `#FF6B5E` | `#FF6B5E` |
| `TagBg` | 分类标签底（配红字） | `#FFF0F1` | `#2A1518` | `#1A0E10` |
| `HeaderBg` | 顶栏背景（= `CardBg`） | | | |
| `HupuRed` | 品牌红，**不随主题变化** | `#E60012` | | |

### 虎扑红只用在小面积

允许：Logo、选中态、指示条、热度、分类标签文字、主按钮、FAB。

**禁止**：整块红色顶栏、整块红色底部导航、红色页面背景。

> AMOLED 下 `CardBg` 本身即纯黑，所以顶栏/底栏改成 `HeaderBg` / `CardBg` 之后，
> 原先「防烧屏把顶栏刷黑」的逻辑自动保留，不需要额外分支。

## 二、层级

页面层级靠 **背景色 + 间距 + 字重**，不靠阴影。

```
Feed Card   阴影 1dp      圆角 16dp   内边距 16dp
顶栏/底栏   无阴影        靠 0.5dp 分割线分层
缩略图      圆角 12dp     112×70dp（16:9）
分类标签    圆角 999dp    TagBg 底 + HupuRed 字
头像/FAB    圆形
```

字号：

| 元素 | Size | Weight |
|---|---:|---|
| 页面标题（虎扑 / 我的） | 20~24sp | ExtraBold |
| Feed 标题 | 17sp | Medium |
| Tab | 15sp | 选中 Bold |
| 摘要 / 正文 | 14~15sp | Regular |
| 标签 / 互动数 | 11~12sp | Regular |

## 三、导航

底部导航为 **首页 / 发现 / 我的** 三项：

- 白底（`CardBg`）+ 顶部 0.5dp 分割线，**不使用红色背景和白色胶囊**
- 选中态 = 红色图标 + 红色粗体文字；未选中 = `TextSecondary`
- 搜索不占导航位，入口在**首页 / 发现页顶栏的搜索图标**
- 本地收藏功能已移除；帖子收藏走虎扑账号，入口在「我的」

首页 Tab（推荐 / 热榜 / 关注）用**下划线式**：选中红字 + 3dp 红色指示条，
不再用大面积色块胶囊。

## 四、发现页网格

243 个专区若用列表排布需滚动约 16000dp，改 5 列网格后约 3200dp。

- 列数常量 `ZONE_GRID_COLUMNS = 5`，每格约 63dp
- 每格放不下「关注」按钮，因此：**已关注在 logo 右下角显示对勾角标，长按整格可关注 / 取关**，
  专区详情页右上角仍有常规关注按钮
- 列数权衡（基于 243 个专区名的真实字数分布）：

  | 列数 | 每格宽 | 名称截断比例 |
  |---|---:|---:|
  | 4 列 | ~79dp | ~0% |
  | **5 列** | **~63dp** | **~16%** |
  | 6 列 | ~52dp | ~40% |

  再密就得让名称换两行，否则「步行街主干道」这类 6 字名会被截断。

「我的关注」和「热门专区」两栏保持原样：前者项数少且需要取关按钮，后者本就是图标行。
